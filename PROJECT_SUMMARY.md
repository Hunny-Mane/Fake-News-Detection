## 🚀 Getting Started

### **Quick Start**
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `python run.py`
3. Open browser: `http://localhost:5000`

### **Alternative Methods**
- Direct start: `python app.py`
- Demo mode: `python demo.py`
- Testing: `python test_app.py`
